폐허가 된 전장에서,
고장 나기 전에 더 강한 기체가 되어라.

자동으로 사격하고, 수동으로 구르고,
매 웨이브마다 로봇을 다시 조립하세요.

▣ 조작법 // CONTROLS

공격은 자동입니다. 당신이 직접 할 일은 두 가지뿐입니다.

이동 // W A S D

포위망을 뚫고 적의 공격 예고 범위에서 빠져나옵니다.

구르기 // SPACE

짧은 무적 시간을 가진 회피 기동입니다. 구르는 동안에는 조준과 사격이 잠시 멈춥니다.

▣ 전투 프로토콜 // 20 WAVES

컴스톡은 자동공격 기반의 웨이브 서바이벌 로그라이크입니다. 사방에서 밀려오는 좀비를 뚫고 살아남은 뒤, 획득한 자원으로 다음 전투에 맞는 기체를 설계하세요.

WAVE 20 // 좀비 군집체

마지막 웨이브에는 돌진, 잔해 낙하, 증원 소환을 사용하는 거대한 2페이즈 보스가 기다립니다. 여기까지 버틸 기체를 만드는 것이 이 게임의 목표입니다.

▣ 런 루프 // RUN LOOP

웨이브 하나가 끝날 때마다 아래 네 단계를 돌며 기체를 다시 짭니다.

01 // WAVE BATTLE

이동과 구르기에 집중하세요. 장착한 무기는 가장 가까운 적을 자동으로 추적합니다.

02 // AI CORE

레벨이 오르면 세 가지 증강 중 하나를 골라 이번 런의 방향을 정합니다.

03 // MODDING BAY

전장에서 회수한 파츠를 장착하고 로봇의 구조와 능력치를 다시 조립합니다.

04 // SHOP

무기와 디스크를 구매하고, 원하는 품목은 잠가 다음 기회를 노립니다.

▣ 정답 없는 조립 // BUILD

“더 좋은 파츠”보다 중요한 것은 지금 이 기체에 맞는 파츠입니다.

  • 다중 무기 소켓

    여러 무기가 각자의 쿨다운으로 동시에 자동 사격합니다.

  • 로봇 모딩

    장갑, 코어, 다리, 헬멧과 디스크 슬롯을 직접 교체합니다.

  • 5단계 장비 등급

    일반부터 레전더리까지, 같은 장비도 등급에 따라 전혀 다른 전력이 됩니다.

  • 위험한 조합

    타입이 맞지 않는 무기도 장착할 수 있지만 무게와 효율의 대가를 치릅니다.

  • 양날의 디스크

    한 능력을 올리는 대신 다른 능력을 포기해 빌드를 비틉니다.

SYSTEM LOG

화력, 생존, 기동성—
셋을 모두 가질 수 없다면 무엇을 포기하시겠습니까?
