# 컴스톡 itch.io 설명 적용법

## 파일 구성

- `itchio-description.html`: Description의 `<>` HTML 모드에 붙여 넣을 본문
- `itchio-custom.css`: 커스텀 CSS 권한이 있을 때 `Edit theme > Custom CSS`에 붙여 넣을 스타일
- `preview.html`: 완성된 분위기를 로컬에서 확인하는 미리보기

## 적용 순서

1. itch.io의 `Edit game`에서 **Description** 항목의 `<>` 버튼을 누릅니다.
2. `itchio-description.html`의 내용을 전부 붙여 넣습니다.
3. 커스텀 CSS 권한이 있다면 `itchio-custom.css`를 `Edit theme > Custom CSS`에 붙여 넣습니다.
4. HTML을 넣은 뒤에는 일반 편집 모드와 왕복하지 말고 HTML 모드에서만 수정합니다.

## 커스텀 CSS 권한이 없는 경우 권장 테마색

- 배경: `#15121C`
- 두 번째 배경/패널: `#292238`
- 본문 글자: `#EEE9F2`
- 링크/버튼: `#9A67D6`
- 헤더 글꼴: 픽셀 또는 모노스페이스 계열

설명 HTML의 인라인 CSS는 itch.io가 저장 과정에서 제거합니다. 완전한 프레임·색상 표현에는 계정별 커스텀 CSS 권한이 필요합니다.
