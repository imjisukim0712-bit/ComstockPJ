# 컴스톡 itch.io 설명 적용법

설명 HTML이 **두 벌**이다. 레이아웃도 언어도 다르니 섞지 말 것.

| | `itchio-description.html` | `itchio-description-en.html` |
|---|---|---|
| 언어 | 한국어 | 영어 |
| 레이아웃 | GBJAM-14식 둥근 색 블록 6섹션 | 히어로 + 카드 그리드 |
| 그림 | `images/` 01~55 (19장) | `images/` 60~73 (5장) |
| 프리뷰 | `preview.html` | `preview-en.html` |

## 파일 구성

- `itchio-description.html` / `itchio-description-en.html`:
  Description의 `<>` HTML 모드에 붙여 넣을 본문
- `itchio-custom.css`: 커스텀 CSS 권한이 있을 때 `Edit theme > Custom CSS`에 붙여 넣을 스타일
  (**한국어판 전용**이다 - `.custom-comstock-description` 안쪽만 건드린다)
- `preview.html` / `preview-en.html`: 로컬 미리보기.
  **손으로 고치지 말 것** - `gen_preview.py`가 만든다
- `images/`: 픽셀아트. **01~55는 `gen_banners.py`, 60~73은 `gen_message_art.py` 소유다**
  (`gen_banners.py`의 청소 루틴이 60번 이상은 안 지우게 막아 뒀다)
- `gen_banners.py`: 한국어판 그림 생성기(게임보이식 4색)
- `gen_message_art.py`: 영어판 그림 생성기(램프 5줄 24색)
- `gen_preview.py`: 설명 HTML → 프리뷰 생성기.
  인자로 파일 이름을 주면 그쪽 프리뷰를 만든다 (`python gen_preview.py itchio-description-en.html`)

## ★ 영어판의 조작키는 그림으로 굽고 FEATURES는 안 구운 이유

**itch.io는 저장할 때 인라인 `style`을 지운다.** 그래서 `style`로만 칠한 구역은 실제
페이지에서 디자인이 통째로 사라진다. 조작키 안내는 색·둥근 모서리·키캡 테두리가 내용의
절반이라 글자만 남으면 뜻이 반쯤 죽는다. 그래서 **한 장의 그림(`60_controls.png`,
552x256)으로 구워** 그 검열을 통과시켰다.

**반대로 FEATURES 카드는 굽지 않았다.** 문장이 길어 그림에 박으면 좁은 화면에서 비정수
배율로 줄어들며 글자가 뭉개지고, 번역·검색·스크린리더에서도 사라진다. 카드는 HTML로 두고
**128px 아이콘 4장만** 넣어 품질을 올렸다.

## 영어판 그림 만드는 법

```
python ItchIO/gen_message_art.py
python ItchIO/gen_preview.py itchio-description-en.html
```

### `gen_banners.py`의 4색 변환과 달라진 점

1. **알파 프리멀티플 후 축소** - Pillow는 RGBA를 그냥 섞어서 투명 픽셀의 검정이 가장자리로
   번진다. 곱해 두고 줄인 뒤 되나눠야 테두리가 안 죽는다.
2. **원본 여백을 먼저 잘라낸다**(`getbbox`) - 안 자르면 지정한 높이가 "캔버스 높이"가 돼
   그림이 칸 안에서 작게 들어간다.
3. **램프 5줄 24색**(강철/주황/크림/보라/올리브 + 파랑) - 명도만 보고 주황 4단계로 누르면
   강철·뼈·감염체가 전부 같은 색이 된다.
4. **★ 램프 선택은 원본 색으로, 단계 선택은 보정한 명도로 한다.** 채도를 올린 색으로 램프까지
   고르면 보스의 카키색 뼈가 임계값을 넘어 통째로 주황(용암 덩어리)이 된다.
5. **★ 무채색 임계값은 채도 0.07이다.** 좀비 피부가 채도 0.10이라 0.13으로 두면 무채색으로
   분류돼 차가운 회색이 되고 시체 느낌이 사라진다.
6. **림 라이트 + 바닥 그림자** - 실루엣 좌상단 1px을 밝히고 발밑에 폭이 다른 타원 3장을 깐다
   (한 장짜리 3px 타원은 이 크기에서 그냥 회색 막대로 보인다).

### ★ 작은 글자에 Orbitron을 쓰지 말 것

게임 UI 폰트가 Orbitron이라 그대로 썼더니 **10px 이하에서 임계값을 먹이면 A가 R로, S가 9로
뭉개진다**(실제로 키캡이 "R 9 D", 배지가 "RUTO"로 나왔다). 자소가 기하학적이라 획이 붙는다.
**큰 제목(13px 이상)만 Orbitron, 키캡·라벨은 Consolas Bold**로 간다.

> `preview.html`을 따로 손보면 반드시 설명 HTML과 어긋난다(실제로 `alt` 문구가 양쪽에
> 낡은 채 남아 있었다). 그래서 프리뷰는 생성물이다.

## 레퍼런스에서 가져온 것 - 그림 스타일 **과** 레이아웃

레퍼런스: <https://itch.io/jam/gbjam-14>

처음 두 번은 **그림 스타일만** 흉내 내다 빗나갔다. 실제로 가져와야 했던 것은 레이아웃이다.
그 페이지의 CSS를 읽어 문법을 그대로 옮겼다.

| 레퍼런스 | 여기서 | 옮긴 방식 |
|---|---|---|
| `.custom-section` (둥근 색 블록, 배경색 교대) | 주제별 섹션 6개 | `div.custom-section` + `border-radius:16px` |
| `h2 { font-size:4em; text-align:center }` | 가운데 큰 제목 | `1.75em`으로만 줄임(본문 칸이 553px) |
| `section > p { width:80%; margin:auto; text-align:center }` | 리드문 | 그대로 |
| `ul > li { width:47.5%; border-radius:1em }` 카드 2열 | 조작 2장 / 런 루프 4장 | `table.custom-cards`의 `td` |
| `.custom-rules-accuracy` (그림 옆 + 글, 넓은 카드) | 웨이브 20 보스 | `table.custom-wide` |
| `ul.custom-criteria li:nth-of-type(2n){row-reverse}` | 빌드 5줄 지그재그 | **`ul`+flex 그대로** |
| `.custom-splash-container` (가로 갤러리) | 적 6종 | `table.custom-gallery` 3칸씩 2줄 |
| `.custom-pixel-img { image-rendering:pixelated }` | 전 그림 | 그대로 |

**flex(`ul>li`) 대신 `table`을 쓴 곳이 있는 이유**: itch.io가 인라인 style을 지우므로,
커스텀 CSS 권한이 없어도 2열 그리드가 유지되어야 한다. `table`은 속성(`width`,`align`)만으로
버틴다.

**단 빌드 목록만은 `ul`+flex다.** `table` 자동 레이아웃은 지정한 폭을 *최솟값*으로만 취급해서
96px로 묶으려던 아이콘 칸이 계속 반쪽(239px)까지 벌어졌다.

## 그림 ↔ 자리 대응 (19장)

| 자리 | 파일 | 크기 |
|---|---|---|
| 인트로(왼쪽) | `01_title` | 200x196 |
| 조작 카드 2장 | `10_move` `11_roll` | 140x98 / 140x108 |
| 웨이브 넓은 카드 | `20_boss` | 180x130 |
| 런 루프 카드 4장 | `30_battle` `31_core` `32_bay` `33_shop` | 112x70~88 |
| 빌드 지그재그 5줄 | `40_sockets` `41_modding` `42_grades` `43_risky` `44_disc` | **96x96 고정** |
| 적 갤러리 6칸 | `50_zombie` … `55_leader` | **96x96 고정** |

정사각 아이콘은 자리 규격이 고정이라 `save(trim=False)`로 여백을 남긴다.
나머지는 세로 여백을 잘라 낸다(간격은 CSS가 정한다).

## 그림 만드는 법

게임의 실제 스프라이트(`Assets/Resources`)를 게임보이식 4색 픽셀아트로 바꾼다.

1. 작은 픽셀 격자로 축소(LANCZOS) - 여기서 픽셀 크기가 정해진다
2. 밝기를 **4색 팔레트로 양자화** - 게임보이의 4단계 녹색 자리에 itch 주황 4단계
   (`#17100E` 외곽선 / `#8A3B22` 그늘 / `#FA5C2F` 기본 / `#FFD29B` 하이라이트)
3. 실루엣을 1px 부풀려 **어두운 외곽선**
4. **NEAREST로 2배 확대**

### 이번에 걸린 함정

- **★ 3번을 빼면 형태가 통째로 뭉개진다.** 양자화가 명암 대비를 4단계로 눌러 배경과 실루엣
  경계를 지우기 때문이다. 레퍼런스가 전부 굵은 외곽선을 두른 이유가 이것이다(장식이 아니다).
- **★ 픽셀아트를 회전시키지 말 것.** 「위험한 조합」 아이콘에 무기 두 자루를 엇갈리게 놓으려고
  `rotate`를 걸었더니 형태가 사라졌다. 지금은 근접무기 한 자루만 놓는다 -
  **레퍼런스의 아이콘도 전부 소재 하나짜리**이고, 뜻은 옆 글이 진다.
- **48px 칸에 소재 둘은 안 들어간다.** 둘 다 뭉갠다.

### ★ CSS로 이미지를 늘리지 말 것

픽셀아트는 **원본 크기 1:1**로 둔다. `.custom-pixel-img`는 `width:100%`가 아니라
`max-width:100%` + `image-rendering:pixelated`다.
줄여야 할 때는 **정수 분수 배율**로만 줄인다 - 좁은 화면 갤러리를 칸 폭에 맡겼더니
96 → 87px(0.9배)이 걸려 픽셀 크기가 들쭉날쭉했다. 지금은 정확히 절반인 48px로 못 박았다.

> 이전 버전(패널형 배너)은 본문 칸 폭 553px에 맞춘 기준 폭 560 + 3배 렌더였다.
> 지금은 그 전제를 쓰지 않는다.

## 적용 순서

> **영어판(`itchio-description-en.html`)은 올릴 그림이 5장뿐이다** -
> `60_controls.png` / `70_guns.png` / `71_bot.png` / `72_boss.png` / `73_cute.png`.
> 자리표시자는 `IMG_60_CONTROLS` ~ `IMG_73_CUTE`이고 규칙은 아래와 같다.
> 히어로 이미지는 아직 자리표시자(`여기에_업로드된_이미지_URL`)로 비어 있으니 따로 채운다.

1. itch.io `Edit game`의 Description에서 **일반(리치 텍스트) 모드**로 `images/`의 PNG
   **19장**을 업로드한다. 업로드하면 `https://img.itch.zone/...` 주소가 생긴다.
2. `<>` 버튼을 눌러 HTML 모드로 바꾼 뒤, 방금 올라간 `<img>` 태그의 `src` 주소 19개를
   **업로드한 순서대로** 복사해 둔다.
3. `itchio-description.html`의 내용을 전부 붙여 넣고, `IMG_01_TITLE` ~ `IMG_55_LEADER`
   자리표시자 19개를 2번에서 복사한 주소로 각각 바꾼다.
   (자리표시자 이름은 파일명을 대문자로 한 것과 같다 - `IMG_30_BATTLE` ↔ `30_battle.png`)
4. 커스텀 CSS 권한이 있다면 `itchio-custom.css`를 `Edit theme > Custom CSS`에 붙여 넣는다.
5. HTML을 넣은 뒤에는 일반 편집 모드와 왕복하지 말고 HTML 모드에서만 수정한다.

> 맨 위에 있던 `COMSTOCK // FIELD TERMINAL` 텍스트 띠와 `SURVIVE / REBUILD / REPEAT` 줄은
> **`01_title.png`가 같은 내용을 그림으로 담고 있어 삭제**했다. 되살리려면 이전 버전의
> `<p class="custom-boot">` / `<p class="custom-kicker">` 문단을 그림 앞에 다시 넣으면 된다.

## 이미지를 다시 만들려면

```
python ItchIO/gen_banners.py
```

Pillow로 `Assets/Resources`의 실제 스프라이트를 합성한다. 실행하면 `images/`의 PNG를
**전부 지우고 다시 만든다.** 문구·배치를 바꾸려면 해당 함수만 고치면 된다.

설명 HTML을 고쳤거나 그림을 다시 만들었으면 프리뷰도 다시 만든다.

```
python ItchIO/gen_preview.py
```

자리표시자를 `images/`의 실제 파일로 바꿔 끼우면서 **그림과 HTML의 짝이 맞는지 검사**한다
(빠진 그림 / 안 쓰는 그림을 알려 준다).

## 로컬에서 확인하려면

`.claude/launch.json`의 `itchio-preview`(python http.server 8744)를 띄우고
`http://localhost:8744/preview.html`을 연다. 본문 칸 폭이 itch.io와 같은 553px로 고정돼 있다.

> **`file://`로 열면 안 된다.** 프리뷰 창이 `data:` URL 스냅샷으로 바꿔 버려 상대경로
> 이미지와 CSS가 전부 깨진다.

## 커스텀 CSS 권한이 없는 경우 권장 테마색

- 배경: `#1C1A19`
- 두 번째 배경/패널: `#2A2624`
- 본문 글자: `#F2ECE7`
- 링크/버튼: `#FA5C2F`
- 헤더 글꼴: 픽셀 또는 모노스페이스 계열

설명 HTML의 인라인 CSS는 itch.io가 저장 과정에서 제거합니다. 완전한 프레임·색상 표현에는 계정별 커스텀 CSS 권한이 필요합니다.
