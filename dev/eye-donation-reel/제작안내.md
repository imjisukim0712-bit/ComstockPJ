# 컴스톡 눈알 기증 밈 애니메이션

인스타그램 릴스용 세로 홍보 영상이다. 한국어·영어 버전의 구성과 길이는 같고 대사·자막·엔딩 문구만 다르다. 외부 게시나 업로드는 하지 않았다.

**최신판은 파일명 끝에 `_v2`가 붙은 파일이다.** 좀비의 양쪽 눈을 같은 홍채 색으로 맞췄다. 청록 좀비는 양쪽 모두 청록, 주황 좀비는 양쪽 모두 주황이다. 기존 파일은 이전 버전으로 보존한다.

## 전달 파일

- `Comstock_EyeDonation_KO_1080x1920_v2.mp4`: 한국어 최종 영상
- `Comstock_EyeDonation_EN_1080x1920_v2.mp4`: 영어 최종 영상
- `Comstock_EyeDonation_KO_preview_v2.mp4` / `Comstock_EyeDonation_EN_preview_v2.mp4`: 540×960 저용량 미리보기
- `Comstock_EyeDonation_KO_cover_v2.jpg` / `Comstock_EyeDonation_EN_cover_v2.jpg`: 1080×1920 표지
- `검수_KO.jpg` / `검수_EN.jpg`: 실제 MP4에서 추출한 장면 모음
- `검증결과.json`: 해상도·프레임·오디오·파일 해시·검증 기록

최종 영상은 각각 **1080×1920, 30fps, 23초, H.264, AAC 48kHz 스테레오**다. 자막은 영상에 포함되어 있다. 마지막 **4.3초** 동안 다음 주소와 문구가 나온다.

- 주소: `pyramid-studio.itch.io/comstock`
- 한국어: “좀비보다 먼저 다운로드하세요.”
- 영어: “Download before the zombies do.”

## 연출

| 시간 | 장면 |
| --- | --- |
| 0~3.35초 | 붕대한 컴스톡이 눈 기증 소식을 전한다. |
| 3.35~5.6초 | 누가 기증했는지 궁금해한다. |
| 5.6~8초 | 좀비 친구 둘이 시선을 피하며 수술을 응원한다. |
| 8~8.8초 | 잠시 후. |
| 8.8~12초 | 붕대가 풀리고 컴스톡에게 청록·주황 눈이 생긴다. |
| 12~15초 | 외눈이 된 좀비 둘의 정면 투샷. 음악을 끊고 어색한 정적을 둔다. |
| 15~18.7초 | 컴스톡이 친구들을 알아보고 과장되게 눈물을 흘린다. |
| 18.7~23초 | 게임 로고·다운로드 문구·itch.io 주소. |

[사용자 제공 참고 영상](https://www.tiktok.com/@dinooo.zip/video/7612964150670560519)을 브라우저에서 실제 확인했다. 눈 기증 소식, 친구들의 응원, 새 눈, 외눈 친구들의 반전이라는 구성을 컴스톡으로 응용했다. 원본 영상 프레임·음성·음악은 최종 영상에 포함하지 않았다.

## 소재와 음성

- 컴스톡 원본 `Assets/Resources/Heads/ComstockMk01.png`, 기존 영상용 `dev/football-reel/assets/zombie_head.png`를 디자인 참조로 사용했다.
- 얼굴 바탕은 **imagegen 내장 도구**로 생성한 투명 아틀라스 `assets/heads_atlas.png`다. 눈·입·팔다리·붕대·눈물은 영상 렌더러에서 별도로 움직인다. 프롬프트 전문은 `assets/이미지생성프롬프트.txt`에 있다.
- 게임 로고는 `Assets/Resources/UI/title_logo.png` 원본을 사용했다.
- 한국어는 Windows Heami, 영어는 Windows Zira 합성 음성이다. 로봇·좀비 역할에 약한 음색 가공을 적용했으며 실제 인물의 목소리를 복제하지 않았다.
- 벨 음악과 소품·전환 효과음은 직접 합성했다. 대사 중에는 음악을 낮추고 전체 음량을 보정했다.
- 눈을 떼는 장면, 피, 절단면, 실제 수술 장면은 없다. 게임 플레이 화면이 아닌 코믹 홍보 애니메이션이다.
- itch.io 주소는 프로젝트의 기존 배포 자료에 있는 주소를 사용했다. 외부 페이지 조회 도구가 안전 검사 오류를 반환해 이번 작업에서 현재 페이지 내용까지 재확인하지는 않았다.

## 재제작

`dialogue.json`은 언어별 대사, `render_reel.py`의 `COPY`는 자막, `TIMELINE`은 장면 시간표다. 대사를 수정할 때 두 언어를 함께 반영한다.

1. `make_voices.ps1`: 로컬 Windows 음성 엔진으로 대사 WAV 생성. 샌드박스 밖 음성 엔진 접근이 필요할 수 있다.
2. `build_audio.py`: 대사·음악·효과음 믹스 생성.
3. `render_reel.py --preview`: 장면별 이미지 미리보기 생성.
4. `render_reel.py`: 두 언어 최종 영상 출력.
5. `verify_and_finish.py`: 실제 출력 검사와 저용량 미리보기·표지 생성.

Python은 Codex 번들 런타임(Pillow·NumPy 포함), 영상 인코더는 기존 `dev/pv/_vendor/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v7.1.exe`를 사용한다. 게임 코드·씬·프로젝트 설정과 기존 영상은 수정하지 않았다.
