# 컴스톡 축구 밈 영상

인스타그램 업로드용 한국어·영어 2D 애니메이션이다. 게시/업로드는 실행하지 않았다.

## 전달 파일

- `Comstock_Football_KO_1080x1920.mp4`: 한국어, 4,685,081바이트.
- `Comstock_Football_EN_1080x1920.mp4`: 영어, 4,680,057바이트.
- `Comstock_Football_preview.mp4`: 한국어 저용량 미리보기, 540×960. 업로드에는 위 1080×1920 파일을 사용한다.
- `Comstock_Football_KO_cover.jpg`, `Comstock_Football_EN_cover.jpg`: SIUUU 장면 표지.
- `검수_KO.jpg`, `검수_EN.jpg`: 완성 MP4에서 추출한 대표 장면 모음.
- `검증결과.json`: 해상도, 프레임 수, 음량, 파일 해시, 전체 디코딩 결과.

두 본편 모두 1080×1920 / 30fps / 660프레임 / 22.00초, H.264 영상 + AAC 48kHz 스테레오 음성이다.
음량은 -15.62 LUFS, 최종 AAC의 최대 실제 피크는 -1.16 dBTP로 측정됐다.

## 구성

| 시간 | 장면 |
| --- | --- |
| 0~2.4초 | 축구공 대신 좀비 머리를 쓰는 개그 |
| 2.4~8.4초 | 등번호 7 컴스톡이 드리블하며 좀비 세 명 돌파 |
| 8.4~11.7초 | 슈팅, 골망 충돌, 1:0 득점 |
| 11.7~17.6초 | 달려오기, 점프, 공중 반회전, 양팔을 내리며 착지, SIUUU |
| 17.6~22초 | 게임 로고, 다운로드 문구, itch.io 주소 |

한국어 엔딩 문구: “좀비보다 먼저 다운로드하세요.”

영어 엔딩 문구: “Download before the zombies do.”

주소: `pyramid-studio.itch.io/comstock`. 기존 프로젝트 홍보 자료에서 확인한 주소를 사용했다.
외부 페이지 접근 도구는 안전 검사 오류를 반환해 이 작업에서 현재 페이지 내용을 재확인하지는 못했다.

## 제작 방식과 원본

- `render_reel.py`: 경기장·의상·관절 움직임·슈팅·세레머니·자막을 직접 합성한다. 같은 이미지의 이동만으로 전체 동작을 대체하지 않고 팔/다리 포즈, 점프 높이, 회전과 착지 상태를 시간에 따라 변경한다.
- 원본 얼굴: `Assets/Resources/Heads/ComstockMk01.png`.
- 원본 상대 팀: `Assets/Resources/ZombieMove/*.png`.
- 원본 로고: `Assets/Resources/UI/title_logo.png`.
- `assets/zombie_head.png`: 기존 좀비를 참조해 내장 imagegen으로 만든 영상 전용 투명 머리 소품. 게임 에셋에는 덮어쓰지 않았다.
- `build_audio.py`: 비트·효과음·관중·로봇풍 SIUUU를 합성한다. 실제 호날두 녹음이나 목소리 복제, 외부 음악은 사용하지 않았다.
- `verify_and_finish.py`: 원본 WAV로 최종 음량을 보정하고 영상 전체를 디코딩한다. 본편 2개에서 오류 0건, 각각 660프레임을 확인했다. 음량 보정 시 길이가 늘어나지 않도록 최종 출력은 명시적으로 22초에 맞춘다.
- 게임 코드·씬·프로젝트 설정·기존 PV는 변경하지 않았다.

## 머리 소품 생성 프롬프트

내장 imagegen을 사용했다. 참조 이미지는 `Assets/Resources/Enemy_zombie.png`이고 요청 프롬프트는 다음과 같다.

> 게임 홍보용 2D 애니메이션 소품을 만들어 주세요. 첨부 이미지는 좀비 캐릭터 디자인 참조입니다. 이 캐릭터의 큼직하고 울퉁불퉁한 연회녹색 머리만 단독으로 그립니다. 한쪽은 크고 동그란 검은 눈, 다른 쪽은 가늘고 졸린 검은 눈, 이빨 두 개 난 우스꽝스러운 입과 몇 군데 봉합 자국을 원본과 매우 비슷하게 유지. 원본의 두꺼운 검정 외곽선, 귀여운 SD 카툰, 연한 셀 셰이딩. 축구공처럼 굴릴 코믹 소품이므로 머리 외곽이 완전히 닫힌 둥근 실루엣이고 목, 어깨, 몸, 옷이 전혀 없어야 합니다. 피, 고어, 절단면, 상처 디테일 없음. 하단도 그냥 둥근 녹색 턱으로 닫히게. 캐릭터 하나만 캔버스 가운데 크게, 완전히 투명한 배경 RGBA, 그림자·땅·글자·라벨·흰 배경·체크무늬 없음. 정사각형 고해상도 게임 스프라이트.
