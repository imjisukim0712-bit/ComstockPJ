# 제로투 댄스 - 마시멜로 로봇 버전 (`dev/zerotwo/`)

레퍼런스 영상의 **0:50 ~ 1:05 (15초)** 구간을 사용자가 준 마시멜로 로봇 캐릭터로
다시 만든 것이다.

- 레퍼런스: [요즘 핫하다는 그 곡! 제로투 댄스 Phao - 2 Phut Hon](https://www.youtube.com/watch?v=XZ7FcT5UvOI)
  (채널 `새벽의선율`, 3분 31초, KAIZ remix / 영상 제작 Light night music)
- 결과물: `Comstock_ZeroTwo_15s.mp4` (1280x720 / 30fps / 15.00초), 미리보기 `Comstock_ZeroTwo_15s.gif`

유니티를 쓰지 않는다. `dev/pv/`(게임 PV)와 같은 방식으로 **Python(Pillow)이 프레임을 그리고
ffmpeg이 인코딩**한다. 게임 코드·씬·에셋은 건드리지 않는다.

## 실행

```bash
pip install Pillow imageio-ffmpeg      # ffmpeg이 PATH에 있으면 imageio-ffmpeg은 불필요
cd dev/zerotwo
python3 render_dance.py                                  # 기본값 그대로
python3 render_dance.py --size 1920x1080 --fps 60        # 크게
python3 render_dance.py --audio ~/2phuthon.mp3           # 노래 붙이기(아래 참고)
```

렌더 시간은 1280x720 / 30fps / 15초 기준 약 6분이다(프레임당 0.75초).

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `character.py` | 마시멜로 로봇을 포즈에 맞춰 그린다. 몸통·귀·얼굴·팔·다리·부츠 |
| `render_dance.py` | 배경·잔상·안무·타임라인·인코딩 |

## 원본 캐릭터와 다른 점

### 그림 파일이 아니라 코드로 다시 그렸다

사용자가 준 캐릭터는 **PNG 한 장(정면 정지 포즈)**이라 그대로는 춤을 출 수 없다.
그래서 같은 모양을 `character.py`에 코드로 옮겼다 — 흰 원통 몸통(굵은 검정 외곽선 +
원통 윗면 테두리 + 좌상단 하이라이트), 좌우 귀(오른쪽 귀만 안쪽 구멍이 보인다),
점 눈 + 흰 하이라이트, 웃는 입, 회색 관절 다리, 갈색 부츠.
**픽셀 단위로 같은 그림이 아니라 같은 디자인을 따라 그린 것**이다.

### 팔은 새로 만들었다 (사용자 허용 범위)

원본에는 팔이 없다. **다리와 같은 문법**으로 맞췄다.

- 회색 관절 막대 2단(위팔 88 + 아래팔 84) + 어깨/팔꿈치 볼 조인트 — 다리와 같은 부품
- 손은 **부츠와 같은 갈색 벙어리 장갑**(엄지 혹 하나) — 손과 발이 한 세트로 보인다
- 어깨는 몸통 옆 위쪽(±140, +5)에 붙는다

**팔은 다리보다 길게 잡아야 한다.** 짧게 잡으면 손이 귀에 붙어버려서 제로투 포즈의
핵심인 "팔꿈치를 크게 벌린 삼각형" 실루엣이 안 생긴다(처음에 74/66으로 잡았다가
88/84로 늘렸다).

## 안무

BPM 128로 잡았다. **이 값이면 15초가 정확히 32박(8마디)으로 떨어진다**(15 x 128/60 = 32.0).
바꾸려면 `--bpm`을 쓰되 15초와 마디가 어긋난다는 걸 감안할 것.

- **2박에 한 번 좌우 왕복** — `sway = sin(beat * pi)`. 몸통 좌우 이동 + 기울기 + 발 무게 이동
- **정박마다 몸이 내려앉았다 튀어오른다** — `dip`, 발밑 그림자와 화면 줌 펀치도 같은 값을 쓴다
- **8박(2마디)마다 팔 포즈 블록이 바뀐다** — `BLOCKS`
  1. 양팔 올림 → 2. 왼팔만 볼 옆 → 3. 양팔 올림 → 4. 오른팔만 볼 옆
  블록 경계는 0.6박에 걸쳐 부드럽게 섞는다
- **2박마다 마젠타 잔상이 좌우 번갈아** 터졌다 1박에 걸쳐 사라진다

팔 각도는 **오른팔 기준으로만 적어 두고 왼팔은 `180 - a`로 미러**한다.
화면 절대 각도를 쓰기 때문에 이 식이 곧 좌우 대칭이다.

## 배경

레퍼런스의 화면 문법을 옮긴 것이다 — 어두운 와인색에서 마젠타로 가는 방사형 그라데이션,
캐릭터 뒤에서 박에 맞춰 뛰는 후광, 천천히 떠다니는 분홍 먼지 입자 110개, 비네팅,
가벼운 블룸, 앞뒤 0.4초 페이드.

## 소리

**영상에는 소리가 없다.** 노래(2 Phut Hon)는 저작권이 있어 리포에 넣지 않는다.
가지고 있는 음원이 있으면 붙일 수 있다.

```bash
python3 render_dance.py --audio <음원파일> --audio-start 50
```

`--audio-start`는 음원에서 잘라올 시작 지점(초)이다. 기본 50은 레퍼런스의 0:50에 맞춘 값이고,
가진 음원의 길이·인트로가 다르면 이 값을 조정해야 박이 맞는다.
이미 렌더한 mp4에 직접 붙이려면:

```bash
ffmpeg -i Comstock_ZeroTwo_15s.mp4 -ss 50 -t 15 -i <음원파일> \
       -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -shortest 결과.mp4
```

## 함정 (다시 만질 사람을 위해)

- **외곽선 두께는 한 가지 규칙으로 통일해야 한다.** `_dot`/`_capsule`/몸통은 모두
  "외곽선을 먼저 굵게 깔고 채움으로 안쪽을 덮어" 밖으로 `OUTLINE/2`만 보이게 한다.
  부츠만 선을 2배로 긋고 다시 덧그렸더니 **부츠 외곽선만 두 배로 두꺼웠다**.
- **미러링하는 조각의 캔버스는 좌우 대칭으로 잡아야 한다.** 부츠 조각 범위를
  발끝 쪽(+x)만 넉넉히 잡았더니 좌우 반전한 **왼쪽 부츠의 발끝이 잘렸다**.
- **두 원이 겹치는 부위는 외곽선을 둘 다 깔고 나서 채움을 둘 다 덮는다.** 손바닥과
  엄지를 하나씩 완성하면 겹치는 자리에 검은 이음매가 남는다.
- **부츠 실루엣은 손으로 찍은 다각형 대신 둥근 사각형 2개(발목 통 + 발)를 합친다.**
  꼭짓점을 직접 나열하면 안쪽에 계단 같은 홈이 생긴다.
- **잔상 색은 원본 명암을 조금만 반영해 납작하게** 만든다. 그대로 살리면 얼굴이 또렷해져
  잔상이 아니라 "옆에 선 두 번째 캐릭터"로 보인다. 좌우 오프셋도 화면 폭의 0.135를
  넘기면 같은 문제가 생긴다.
- **몸통 레이어는 캐시하고 회전만 매 프레임 한다.** 몸통·귀·얼굴은 포즈와 무관하므로
  (깜빡임 3종만 변형) 매번 다시 그릴 이유가 없다.
